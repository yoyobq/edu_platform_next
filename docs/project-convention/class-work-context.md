# 班务工作班级

- 班务管理菜单提供工作班级选择，覆盖学生建档、操行对齐、成绩汇总、评语治理和学籍卡 Lab。
- 选择源是 `studentPrivateProfileClassOptions`；本地建班继续使用其独立的班级代码与核对流程。
- 仅菜单选择改变工作班级，按账号保存在当前浏览器。无保存值时单班自动选择、多班明确选择；网络错误不删除保存值。
- 页面临时切班不改变工作班级。显式链接范围优先于工作班级；无工作班级时保留页面已有默认规则。
- 菜单切班通过路由导航触发页面切换，只有导航获准后才保存工作班级；未保存内容或进行中的写操作由页面拦截。其他标签页不会强制切换当前工作内容。
- `classId`、`semesterId`、`studentId`、`commentKind` 是治理导航范围。页面仍通过自身 API 校验权限，不能用菜单班级列表代替授权。
- 学籍卡缺项链接携带原学生检查地址，目标页提供返回检查入口。返回后重新预检，不复用过期检查结果。
- 学籍卡展示可搜索的班级学生名单，点击学生自动检查材料；显式链接中的学生仍自动定位并检查。
  “生成并下载”在生成成功后自动下载 DOCX，下载失败保留生成结果，可点“重新下载”重试而不重复生成。
  材料阻塞和只读权限继续按后端检查结果限制出卡，材料提醒保留展示；批量生成须由管理员或教务员显式勾选并发起。
- 全局 provider/API/storage/URL adapter 归 `features/class-work-context`；共享状态契约和展示归 `entities/class-work-context`；app 挂载 provider 并向侧栏注入控件。
- 前端自动测试使用 GraphQL mock 验证交互和请求范围，不代表后端持久化或上游真实联调。

- 五个页面统一使用 `entities/class-work-context` 公开的 `ClassWorkScopeBar`，在标题栏右侧展示紧凑班级下拉、临时查看及返回入口，窄屏随标题布局换行。组件受控，不请求数据、不写默认班级；各页面提供自身可操作班级和切班保护回调。

- 班务链路页面采用统一的 `max-w-7xl` 内容宽度、24px 页面边距与区块间距；工具栏按静态内容容器使用 16px 内边距，行内操作使用 8px 间距。班级选择使用项目主题下的标准描边 Select，组件自身管理背景、悬停、焦点与禁用态。

- 页面主工具栏统一左侧承载信息、筛选与进度，右侧承载操作按钮；空间不足时自然换行，按钮组保持右对齐。评语治理的完成度标签、进度条和已完成/总数在同一行展示。

- 学籍卡生成及首次自动下载期间拦截站内导航并对刷新／关闭页面提供浏览器提醒。操作结束后不自动执行被拦截的导航，用户可留在原页查看下载入口或错误，也可确认继续离开；普通材料预检不启用写操作级拦截。

- 学籍卡批量导出限定当前班级：搜索过滤不清除勾选，表头全选只作用于搜索结果，另提供全班全选。
  串行复用单人生成及授权下载，材料提醒继续导出，阻塞或失败跳过；结束下载一个 ZIP，附带导出结果 CSV。
  可停止后续处理、继续待处理项或重试未完成项；成功项不重复生成，下载失败优先复用未过期凭证。
  批量执行及打包期间拦截导航、禁用切班与单人出卡；结果和文档只在页面内存保存，离开或刷新不恢复。
